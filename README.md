# 📖 Information
- Comes with 4 types of armor blocks: Light Armor, Steel Armor, Composite Armor, and Reinforced Armor!
- Armor comes in a diverse array of colors and patterns!
- Every type of armor block comes with a full block variant, slabs, stairs, vertical slabs, and vertical stairs in all the previously mentioned colours!

# 🤝 Compatibility
- Comes with built-in [Valkyrien Skies physics data!](https://wiki.valkyrienskies.org/wiki/Block_Properties)
- Comes with built-in [Create: Big Cannons toughness and hardness values!](https://github.com/Cannoneers-of-Create/CreateBigCannons/blob/multiversion/src/main/resources/data/createbigcannons/block_armor/tags/obsidian.json)
- This mod should work with any other!
